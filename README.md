# Manual QA Portfolio — SauceDemo

This repository contains manual testing documentation for the SauceDemo demo e-commerce application.

**Application under test:** https://www.saucedemo.com/

## Project goal
Practice a structured manual QA workflow: define scope, write test cases, execute checks, and report results clearly.

## Scope covered
- Product catalog presentation
- Add-to-cart behavior
- Cart badge update
- Product button state change (`Add to cart` → `Remove`)
- Cart contents and displayed price
- Removing a product from the cart

## Results
All five checks documented in [Test Execution Report](docs/test-execution-report.md) passed in the recorded test run. This is a small manual testing exercise, not a claim of complete application coverage.

- [Test Plan](docs/test-plan.md)

## Test environment

- Test type: Manual functional testing

## Limitations
- Browser, operating system, and exact execution date were not recorded.
- Only the five checks listed in the execution report were performed and reported.
- No defects were reported in these checks; this does not establish that the application is defect-free.
- No payment, checkout, security, accessibility, performance, or cross-browser testing is claimed.
